# Base de Datos

Este directorio contiene los esquemas de datos del proyecto Internal Marketplace.

## Archivos
- `schemas/data-model.md` → Modelo de datos general.
- `schemas/usuarios.md` → Entidad Usuarios.
- `schemas/colaboradores.md` → Entidad Colaboradores.
- `schemas/habilidades.md` → Entidad Habilidades.
- `schemas/proyectos.md` → Entidad Proyectos.
- `schemas/postulaciones.md` → Entidad Postulaciones.
- `schemas/asignaciones.md` → Entidad Asignaciones.

## Motor recomendado
Amazon DynamoDB (AWS Free Tier) o Amazon RDS (t2.micro/t3.micro) bajo opción IaaS.
